# Contributing to JoinPreflight

Thank you for helping improve JoinPreflight.

1. Open an issue describing the bug or feature, including a small reproducible dataset where possible.
2. Fork the repository, create a topic branch, and make your change.
3. Install development dependencies using `python -m pip install -e ".[dev]"`.
4. Add or adjust tests, then run `python -m pytest -v`.
5. Open a pull request explaining the use case, behavior change, and any limitations.

Avoid committing personal data, credentials, large CSV exports, virtual environments, or generated reports.
